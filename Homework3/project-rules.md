# Project Rules

- Use HTML5, CSS3, and Vanilla JavaScript only.
- Do not use Bootstrap, Tailwind, jQuery, or external CDNs.
- Prefer semantic HTML elements.
- Use const by default, let only when reassigned.
- Never use innerHTML or inline event handlers (onclick=...).
- Write user input to the page with textContent only.
- Dates are UTC ISO 8601 strings with a Z suffix; never parse local date strings.
- Never count time with a decrementing counter; always compute from Date.now().
- The page must work at 375px width.
- Serve the page through Live Server, never file:///.
- One slice per prompt, one slice per commit.
