
# Homework 1 - Production Portfolio

## Project Goal
Build a responsive, accessible, and secure personal
portfolio using HTML5, CSS3, and Vanilla JavaScript.

## Technology
- Semantic HTML5
- CSS Flexbox and Grid
- Vanilla JavaScript ES6+
- Git for version control

## Task Breakdown

### T-01: Semantic HTML
- Create header, nav, main, section, and footer.
- Add accessible skip navigation link.
- Use exactly one h1.
- Avoid unnecessary div elements.

### T-02: CSS Design
- Implement box-sizing reset.
- Define CSS variables for design tokens.
- Build a responsive layout using Flexbox and Grid.
- Support 375px mobile viewport.

### T-03: JavaScript
- Implement accessible dark mode toggle.
- Store user preference in localStorage.
- Use addEventListener instead of inline handlers.

### M1: Accessibility Audit
- Check WCAG 2.2 AA contrast requirements.
- Verify landmarks and accessible labels.

### M2: Keyboard Navigation Audit
- Test Tab, Shift+Tab, Enter, and Escape.
- Ensure no keyboard focus trap.

### M3: Security
- Configure strict Content Security Policy.
- Remove inline event handlers.
- Avoid unsafe innerHTML.

### M4: Performance
- Optimize image assets.
- Prevent layout shifts.
- Run Lighthouse audits.
- Target a score of 100.

## Verification
Each task must be tested before moving to the next.
Git commits must represent isolated changes.
